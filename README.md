# # Java - Fundamentos

Repositório dedicado aos meus estudos dos fundamentos da linguagem Java.

## Conteúdos estudados
- Variáveis e tipos de dados
- Operadores aritméticos, relacionais e lógicos
- Estruturas condicionais
- Estruturas de repetição
- Métodos

Os exercícios estão organizados na pasta `src`, separados por assunto, para registrar minha evolução no aprendizado de Java.
